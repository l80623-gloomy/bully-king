## 二、最終提示詞

### EV18 安全鴨需要休息

> Use case: illustration-story. Asset type:《霸凌王》職場安全與霸凌防治互動遊戲事件圖。製作 EV18「安全鴨需要休息」，1536×1024 橫式、不透明滿版 PNG。嚴格延續參考圖的手工剪紙拼貼風格：厚紙纖維、分層紙片、柔和陰影、低飽和灰綠與木棕，安全鴨服裝沿用亮黃色身體、橘色嘴喙、深藍安全帽、鼠尾草綠領巾。場景取自 BG09 聚餐／活動場地，但改為活動區旁較安靜、通風、有遮蔭的休息角落；遠方只保留模糊的活動布置，不要文字。穿著厚重安全鴨吉祥物身體服裝的真人工作人員已離開主要活動區，坐在穩固長椅上休息，頭套已完整取下並放在身旁地面或椅面，露出一位成年工作人員的頭部；服裝胸前可微微拉開散熱，但不要脫到不雅。工作人員只是疲憊、流汗與需要休息，保持清醒坐姿，沒有昏倒或醫療症狀。一位同仁蹲在側前方與他平視、關心確認狀況；另一位同仁站在稍後方，手持無字手機準備通知現場負責人。旁邊放一瓶無標籤飲水與摺疊扇，但不示範醫療處置。構圖停在「是否立即停止表演、安排休息並通報負責人」的決策前，氣氛關切、尊重、不搞笑。人物姿勢與朝向有變化，三人形成清楚三角構圖。無任何文字、數字、標誌、品牌、對話框或浮水印。禁止嘲笑、暈倒特寫、急救或醫療診斷、酒類、強迫繼續表演、將不適者當成娛樂；不要把 UI 吉祥物畫成獨立活著的角色，必須清楚是被真人穿著的服裝與已取下的頭套。

參考素材：BG09 尾牙與部門聚餐、安全鴨提示姿勢、安全鴨警示姿勢。

### END01 封起的案卷

> Use case: stylized-concept. Asset type:《霸凌王》Roguelite 結局圖鑑共用象徵插畫。製作 END01「封起的案卷」，1536×1024 橫式、不透明滿版 PNG，無任何文字。嚴格沿用參考圖的精緻手工剪紙拼貼質感：厚紙纖維、分層紙邊、微小不規則剪裁與柔和投影。畫面是偏俯視的安靜辦公桌，中央稍偏左放一疊完全空白、沒有標籤的米灰色案卷與資料夾，被一條寬的低彩度灰藍紙帶交叉束起，紙帶沒有印章或字樣；束帶末端壓在案卷下方，呈現程序被封存、停滯的感受，但不要鎖鏈、封條文字或犯罪意象。畫面後方景深處只有一張無人辦公椅，椅面被狹窄冷光勾勒，周圍光線逐步收窄、桌面邊緣沉入灰綠陰影。右下角留一些乾淨負空間，方便遊戲 UI 疊加。配色為低彩度灰綠、石板藍、米灰、深木棕，僅保留極少冷白光。整體沉靜、克制、制度停滯，不恐怖、不悲情煽動。禁止人物、手、鎖鏈、封蠟、法槌、警察物件、墓碑、血跡、破損照片、可讀文字、數字、標誌、浮水印或對話框。

參考素材：EV14 漂亮數字與真實感受。

### END02 重新打開的門

> Use case: stylized-concept. Asset type:《霸凌王》Roguelite 結局圖鑑共用象徵插畫。製作 END02「重新打開的門」，1536×1024 橫式、不透明滿版 PNG，無任何文字。嚴格延續參考圖的手工剪紙拼貼風格：清楚紙纖維、分層剪紙邊緣、柔和立體投影、克制的辦公空間。構圖以一扇位於畫面偏右的辦公室門為核心，門由原本封閉的位置重新打開約四十五度；門外走廊與門內房間各有一道不同方向但同樣溫暖的柔黃光，在門檻處交會，象徵發聲、求助與溝通管道重新開啟。門旁矮櫃上整齊放著一個完全空白的米白資料夾與一支筆，資料夾不得有標籤。畫面不出現人物，避免限定任何角色；左側與下方保留適量負空間供遊戲結局文字疊加。門後不可出現神秘人影；室內只需看見一張空椅、圓角桌面與一盆植物的局部，氛圍安全、邀請、尚待踏入，而非宗教或奇幻天堂。配色從走廊的灰綠與石板藍漸變到門內的暖米白與柔和琥珀色。禁止文字、數字、門牌、標誌、浮水印、人物、伸出的手、醫療符號、法院意象、過曝聖光、恐怖黑影、對話框或握手廣告感。

參考素材：EV14 漂亮數字與真實感受、BG12 辦公室走廊與門口。

### END03 修補過的紙張

> Use case: stylized-concept. Asset type:《霸凌王》Roguelite 結局圖鑑共用象徵插畫。製作 END03「修補過的紙張」，1536×1024 橫式、不透明滿版 PNG，無任何文字。嚴格延續參考圖的精緻手工剪紙拼貼風格：真實紙纖維、層層剪紙、略帶不規則撕邊、細緻柔和陰影。採接近俯視的桌面構圖：中央是一張大型米白厚紙，曾由左下到右上撕裂成兩半，現在以多條不同色但協調的窄紙條細緻跨縫修補；修補條使用鼠尾草綠、霧藍、暖赭與柔黃，排列不完全整齊但牢靠，裂縫仍看得見，表達修復不等於抹去曾發生的事。紙張四周留下四至六個由不同膚色與衣袖色紙剪成的「手形剪影」，只呈現平面的手形紙片或指尖壓住修補條，不畫真實手臂、不握手、不做企業合作廣告姿勢；各手從不同方向參與，象徵團隊學習與制度改善。桌面放少量無字剪紙工具：安全圓頭剪刀、紙膠帶與幾片剩餘色紙，整齊不凌亂。左上或右上保留乾淨負空間供 UI 疊字。光線由側上方灑入，色調溫暖但克制，呈現踏實、共同承擔、可繼續改善。禁止文字、數字、標誌、浮水印、拼圖圖案、愛心、握手、獎盃、彩帶、醫療縫合或針線、血跡、傷口、完美無裂痕的紙、人物臉孔、對話框。
