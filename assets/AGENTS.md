# 《霸凌王》素材存放規則

使用者於 2026-09-11 要求統一素材資料夾，後續繪圖必須遵守。

- 所有正式圖片（PNG 原圖及 WebP 遊戲版）依用途放入 `assets/images/` 下列三大類：
  - `backgrounds/`：場景背景與空間圖。
  - `characters/`：主角、配角、NPC 與角色立繪。
  - `events/`：事件、情境與互動題目插圖。
- 三大類之下不再建立風格、小樣、批次或角色個人等子資料夾；以檔名前綴與版本辨識，避免目錄再次碎片化。
- 舊版本、未採用風格與比較圖放 `assets/archive/`；不自行刪除或覆蓋。
- 去背遮罩、邊緣放大、疊圖測試與驗證報告放 `assets/qa/`。
- 提示詞、美術設定及製作紀錄放 `assets/docs/`。
- 繪圖完整清單仍保留在 assets 根目錄的原 MD，採局部更新內文版本與進度，不整份覆寫。
- 繼續沿用剪紙拼貼風格；葉經理造型以 images/characters/yeh_葉經理_女性_剪紙_v3.png 為準。
- 新配角建議存為 `images/characters/NPC_角色名_透明立繪_v1.png`；背景存為 `images/backgrounds/BG編號_場景_剪紙背景_v1.png`；情境存為 `images/events/EV編號_情境_剪紙_v1.png`。現有檔名與 WebP 識別名稱保持不變。
- 生成後必須複製到對應的三大類目錄，不只留在工具預設生成目錄。遇同名檔另增版本。
- 透明立繪須檢查真正 alpha 及不同底色；PNG 副檔名或棋盤格外觀不等於透明。
- 移動素材時同步修正 HTML 與 MD 引用，只改必要路徑，保留其他使用者修改。未做瀏覽器測試時不得聲稱實機驗證完成。
