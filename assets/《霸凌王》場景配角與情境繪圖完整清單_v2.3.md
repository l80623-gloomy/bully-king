## 一、場景背景：建議優先建立的共用素材

背景先畫成「無人物、無文字」，之後搭配不同角色，就能支援多個事件。

| 編號 | 場景 | 可以呈現的畫面 | 適用事件 |
|---|---|---|---|
| BG01 | 一般辦公區 | 隔板座位、電腦、文件、公告板 | 新人犯錯、工作分配、資源被剝奪、同事互動 |
| BG02 | 部門會議室 | 投影幕、長桌、散落的報告、空椅子 | 公開否定、建議被忽略、搶功、集體抵制 |

| 所屬角色線 | 配角 | 可以建立的視覺特色 |
|---|---|---|
| 葉經理 | **陳桑：資深業務** | 熟悉業務、拿著客戶資料；表情沉穩，有自己的判斷 |

| 徐課長 | **小杰：年輕作業員** | 年輕、有想法，搭配改善草圖或工作紀錄 |

此外，有幾位雖然不是上述固定配角，卻很值得畫：

- **金姊：**老陳線的小圈圈核心，推動很多排擠與抵制事件，值得優先製作。
- **游廠長：**徐課長的上層壓力來源。
- **高經理：**葉經理線的同級主管，涉及不當管理話術與挖角。
- **總經理：**業績壓力與高層肯定的來源。
- **獨立董事：**董事會質詢的重要人物。
- **安全鴨：**廠慶事件中的吉祥物，可做成有記憶點的特殊素材。

**角色辨識要特別注意：陳桑不是老陳，小宏不是阿宏，雅婷不是小美。**髮型、主色和身形應刻意區分。

## 三、情境插圖：最有畫面感的事件

這類不是單純的人物站姿，而是可以放在事件卡上方的「故事畫面」。

| 編號 | 情境 | 建議構圖 |
|---|---|---|
| EV01 | **公開否定與羞辱** | 報告者站在投影幕旁，主管打斷，同事視線集中或避開；用姿態呈現壓力 |
| EV02 | **午餐時被排除在外** | 一群人圍坐聊天，另一位同仁端著便當站在桌邊，座位形成明顯距離 |
| EV03 | **群組已讀不回** | 手機訊息前景，背景是獨自等在會議室的主管；文字另由介面處理 |
| EV04 | **功勞被拿走** | 一人拿著成果接受稱讚，原提案者手上還留著草稿 |
| EV05 | **責任被推給新人** | 會議桌上多人把報告推向新人，旁觀者正面臨是否出聲的選擇 |
| EV06 | **下班前又收到任務** | 已背起工作包的同仁，面對主管新遞來的一疊文件 |
| EV07 | **鼓起勇氣走進申訴室** | 同仁握著資料站在門口，門內有空椅子；焦點放在「準備開口」 |
| EV08 | **有人願意陪你一起說** | 小魚與小雨並肩走向受理室，沒有拉扯或強迫，呈現陪伴 |
| EV09 | **整理工作紀錄** | 手機、日期便條、電子郵件與事件筆記排列成時間軸 |
| EV10 | **語言落差造成誤解** | 班長指著分類圖，阿迪拿出翻譯手機；畫出雙方需要確認資訊的時刻 |
| EV11 | **找不到工具的新人** | 小凱站在缺了一格的工具板前，旁人有不同反應；不呈現破壞工具的操作細節 |
| EV12 | **趕工中的未遂事故** | 機台停止後，小杰退到安全位置，徐課長面對是否通報的抉擇；不畫血腥傷害 |
| EV13 | **桌上的六封辭呈** | 吳董面前整齊排著六封信，後方是空掉的座位，呼應集體離職潮 |
| EV14 | **漂亮數字與真實感受** | 剪紙畫面左右對照：一側是亮眼圖表，一側是沉默、疲憊的辦公區 |
| EV15 | **申訴進度遲遲不明** | 申訴人拿著收件資料等待，另一側是積壓的案卷與日曆 |
| EV16 | **私下關說的一頓飯** | 餐桌上的邀請與公事資料並置，曾組長面對夏經理的暗示 |
| EV17 | **表面歡樂的團隊活動** | 團隊建立道具旁，仍堆著未減少的工作文件，呈現制度上的荒謬 |
| EV18 | **安全鴨需要休息** | 厚重吉祥物服裝、炎熱的活動場地與注意到不適的同仁；笑點放在活動安排，不放在人受苦 |
| EV19 | **認真傾聽的受理** | 人資放下其他工作，與申訴人平視交談，桌上有清楚整理的資料 |
| EV20 | **願意帶新人的前輩** | 資深同仁與新人一起看流程圖、確認理解，呈現正向互動 |

特別保留 EV08、EV19、EV20 這類正向畫面，讓教材不只有壓迫、責怪和壞結局，也有「實際可以怎麼做」。

## 四、還能延伸的遊戲視覺素材

這些不急著先做，但能增加整體遊戲感：

- **角色表情組：**平靜、疑惑、緊張、不滿、反思、釋然；同一人物維持相同服裝與構圖。
- **選擇後的雙版本插圖：**例如「繼續排擠／邀請入座」「打斷陳述／認真傾聽」。
- **結局象徵圖：**空辦公椅、被封起的案卷、重新打開的門、修補過的紙張等。
- **物件圖示：**工作紀錄本、申訴信封、排班表、工具箱、手機、陪同支援。
- **章節轉場：**會議前、下班後、收到通知、調查開始等剪紙場景。
- **「地獄鏡子」畫面：**鏡子一側是漂亮績效，另一側是事件紀錄；呈現反思，不必畫成恐怖場景。

## 五、建議的第一批

如果要先做一小批、又能立即看出效果，建議選擇：

| 類型 | 第一批內容 |
|---|---|
| 場景背景 4 張 | 部門會議室、茶水間、製造部產線、申訴受理室 |
| 配角 6 位 | 小宏、金姊、林襄理、小杰、邱經理、小魚 |
| 情境插圖 4 張 | 公開否定、午餐排擠、語言溝通、陪同求助 |

共 **14 張**。製作順序建議是**背景 → 配角 → 情境**，先確定人物造型，再畫多人互動，外觀比較容易維持一致。

另外，**選項出現前的插圖應停在「事情正在發生」的時刻**；處分、離職、和解等結果，留到玩家選擇後再呈現，避免圖片提前替故事下結論。

## 六、美術方向摘要與先行小樣

### 6.1 風格結論

繼續採用**剪紙拼貼**，沿用七位主角的視覺辨識；從角色海報調整為可重用的遊戲素材，不另換人物畫風。核心原則是：**角色有個性、背景不搶戲、情境看得懂。**

- **背景：**橫式、無人物、無文字，減少細碎物件、紙紋與強烈陰影，留出角色站位及介面閱讀空間。
- **配角：**延續紙片五官、服裝與比例，採真正透明背景 PNG，不嵌入姓名紙標，方便搭配不同場景；需檢查透明通道，不能以白底或棋盤格冒充透明。
- **情境：**以視線、手勢、姿態及人物距離表達事件，不將立繪簡單並排，也不讓所有人只會皺眉。保留傾聽、陪伴等正向畫面。
- **介面：**插圖維持剪紙特色，對話、姓名、標題與按鈕由乾淨的扁平介面顯示，不畫死在圖片內。
- **一致性：**人物層次較清楚，背景降低對比；同一角色使用既有造型參考。葉經理採女性剪紙 v3。
- **敘事：**選擇前畫面不提前呈現處分、離職或和解結果；涉及玩家決定的不當行為畫面，應標示為對應分支／選擇後素材，避免預設玩家已做出該決定。
