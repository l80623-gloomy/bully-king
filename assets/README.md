# 《霸凌王》素材目錄

版本：v1.6｜整理日期：2026-09-11

正式圖片統一放在 **images**，並依遊戲中的實際用途分為背景、角色與事件三大類；三大類之下不再按風格、角色個人或製作批次建立多層目錄。

```text
assets/
├─ images/                     正式圖片
│  ├─ backgrounds/             場景背景與空間圖
│  ├─ characters/              主角、配角、NPC 與角色立繪
│  └─ events/                  事件、情境與互動題目插圖
├─ archive/  舊版、未採用風格、比較圖
├─ qa/       去背遮罩、測試疊圖、檢查報告
├─ docs/     提示詞、美術設定與製作紀錄
├─ 《霸凌王》場景配角與情境繪圖完整清單_v2.3.md
├─ AGENTS.md 後續繪圖必讀的存放規則
└─ README.md 本說明
```

後續繪製主角、配角或 NPC，存入 `images/characters/`；背景存入 `images/backgrounds/`；事件與情境插圖存入 `images/events/`。同一分類內透過角色名、BG／EV／NPC 前綴與版本號辨識。PNG 原圖與 WebP 用途不同，兩者都保留，不視為多餘重複檔。
