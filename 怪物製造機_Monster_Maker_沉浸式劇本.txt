【怪物製造機：Monster Maker】企業沉浸式反霸凌劇本

副標題：
每個人都在找怪物。
最後發現怪物是被製造出來的。

====================
故事核心
====================

玩家接受HR委託。

調查一樁職場霸凌案件。

傳聞中。

公司裡有一名極其惡劣的霸凌主管。

你的任務：
找出怪物。

====================
第一章：離職者的證詞
====================

離職員工小美表示：

我每天都很焦慮。

每次Teams跳出通知。

我都會心跳加速。

我不敢發言。

我怕被笑。

玩家開始收集線索。

====================
第二章：消失的新人
====================

新人阿宏到職四個月後離職。

離職面談內容：

我不知道自己哪裡做錯。

但我知道。

這裡不歡迎犯錯的人。

====================
第三章：主管檔案
====================

玩家查看主管紀錄。

績效第一名。

部門效率第一。

升遷速度最快。

但員工滿意度最低。

玩家自然將主管列為首要嫌疑人。

====================
第四章：矛盾證詞
====================

資深同仁表示：

主管其實不壞。

他只是要求比較高。

另一位同仁表示：

主管沒有惡意。

只是講話比較直接。

案件開始變得模糊。

====================
第五章：模擬調查
====================

系統要求玩家協助判斷管理情境。

情境一：
新人犯錯。

A 群組提醒
B 私下討論
C 會議檢討

情境二：
同仁質疑決策。

A 當場反駁
B 追問原因
C 會後處理

玩家不知道的是。

系統正在累積人格數據。

====================
第六章：文化感染
====================

調查發現。

不只是主管。

資深員工開始酸新人。

新人開始排擠新人。

冷嘲熱諷成為日常。

原來怪物並不只有一個。

====================
第七章：怪物工廠
====================

系統還原時間線。

第一代主管。
被羞辱。

第二代主管。
複製羞辱。

第三代主管。
正常化羞辱。

企業文化開始形成。

====================
第八章：揭露真相
====================

HR完成分析。

玩家按下：

查看兇手。

畫面顯示。

第一名嫌疑人：主管。
相似度48%。

第二名嫌疑人：資深員工。
相似度33%。

第三名嫌疑人：總經理。
相似度51%。

第四名嫌疑人：玩家。
相似度93%。

====================
第九章：鏡子測試
====================

系統開始播放玩家剛才的選擇。

每個選擇都切換受害者視角。

你認為是提醒。

對方感受到羞辱。

你認為是要求。

對方感受到恐懼。

你認為是玩笑。

對方感受到排擠。

====================
最終章：怪物製造機
====================

螢幕出現一句話。

怪物並非天生存在。

而是在一次又一次合理化之中誕生。

當人們說：

我是為你好。

大家都這樣。

以前也是如此。

你太玻璃心了。

怪物便開始被製造。

====================
四大結局
====================

結局一：怪物本體
你成為文化的延續者。

結局二：沉默共犯
你沒有霸凌。
但你選擇旁觀。

結局三：覺醒者
你發現問題並停止複製。

結局四：終結者
你打破組織世代循環。

====================
最後一句
====================

你一直在尋找怪物。

直到發現。

真正可怕的不是怪物。

而是讓怪物不斷被製造的文化。
