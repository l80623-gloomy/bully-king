# 霸凌王（Bully King）

一款用「反差／換位思考」做職場霸凌防治教育訓練的互動網頁遊戲。玩家在遊戲裡扮演加害者角色，親手做出一個個看似「合理」的管理決策，最後才在證詞與隱藏數據中，看見這些決策造成的真實傷害——藉此讓受訓者從加害者視角，重新認出自己或身邊可能發生過的職場不法侵害樣態。

目前為公司內部教育訓練素材，**尚未公開發布**。

## 這是什麼

- **單一 HTML 檔案、免安裝、免建置**：`《霸凌王》.html` 用瀏覽器直接開啟即可遊玩，所有邏輯、劇本、CSS 都寫在同一個檔案裡，沒有任何外部依賴或伺服器需求。
- **七個角色線，涵蓋六種霸凌方向**：上對下（葉經理）、下對上（徐課長）、平行同事（老陳）、集團高層（吳董）、外籍移工（阿迪）、人資／申訴受理（曾組長），以及唯一一個「被霸凌者本人視角」（小雨）。
- **雙軌數值系統**：畫面上看得到的三圍（每位角色語意不同，例如威嚴／績效／服從度）＋全程隱藏、只在最終審判揭曉的恐懼、毒性、風險、安全感。
- **Roguelite「本輪詞條」**：每輪開局用洗牌抽取機制隨機套用一個限定規則（雙重命運骰、玻璃心全開、如履薄冰⋯），讓每次重玩都有不同變化。
- **成就牆、稱號牆、結局圖鑑**：14 個跨角色成就、依角色人格分析判定的稱號、每位角色 6+1 種結局（含 1 個隱藏結局），全部支援收集與重複遊玩。
- **開發者模式**：連續快速點擊首頁的鎖定按鈕即可進入，可直接檢視、覆寫每個角色╱情境╱選項的數值加減，並附有成就、結局、稱號三份判定條件說明頁，方便內容調整與測試。
- **剪紙拼貼風格美術**：七位主角、二十餘位配角 NPC、場景背景與情境插圖皆採統一的剪紙拼貼視覺風格，詳見 [`assets/README.md`](assets/README.md) 與素材完整清單。

## 怎麼玩 / 怎麼測試

直接用瀏覽器開啟：

```
《霸凌王》.html
```

- 不需要架站、不需要任何建置指令。
- 首頁可選擇角色、查看版本紀錄、進入成就牆。
- 每個角色都可選「短劇本」或「長劇本」，並可切換「地獄模式」增加難度與解鎖隱藏情境。
- `index.html` 是同步內容的備份／GitHub Pages 用入口檔，功能與主檔案完全一致。

## 專案結構

```text
《霸凌王》/
├─ 《霸凌王》.html          遊戲主檔（唯一需要維護的原始碼）
├─ index.html               與主檔內容同步的入口檔（供 GitHub Pages／備份用）
├─ README.md                本說明
└─ assets/
   ├─ images/                正式圖片（backgrounds／characters／events 三大類）
   ├─ 數值調整覆寫檔/        開發者模式匯出的數值覆寫 JSON（供跨環境校準結局門檻）
   ├─ docs/                  美術提示詞、製作紀錄
   ├─ archive/               舊版素材與已封存文件
   ├─ qa/                    去背檢查、縮圖總覽等驗證用圖
   ├─ AGENTS.md               後續繪圖／存放規則（給協作的 AI 或美術看）
   ├─ README.md               素材目錄總說明（含目前素材清單與快照）
   └─ 《霸凌王》場景配角與情境繪圖完整清單_vX.X.md   美術素材規劃與製作進度總表
```

- 正式部署於公司內部 OHS Portal（`training/bullyingking2026/`），僅供內部教育訓練使用。
- 本倉庫（`l80623-gloomy/bully-king`）為本機開發歷程的備份倉庫。

## 內容注意事項

本遊戲模擬職場霸凌情境，遊玩過程可能引發不適感受。若使用者曾有相關經歷，建議先評估自身狀況，再決定是否繼續遊玩或用於教育訓練場合。依職業安全衛生法第 6 條第 2 項第 3 款，雇主對於執行職務因他人行為遭受身體或精神不法侵害，應採取預防必要措施；本教材可搭配公司實際的申訴管道與職安通報窗口一併說明。
